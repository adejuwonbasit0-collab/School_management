Connect Telegram Bot

1. Open Telegram, message @BotFather, send /newbot and follow the prompts.
2. Copy the token BotFather gives you and paste it below.
3. We'll verify it and register the webhook automatically — no manual setup needed on Telegram's side.

Connect WhatsApp Business

From Meta for Developers → your App → WhatsApp → API Setup, copy the Phone Number ID and a permanent Access Token (System User token, not the 24h test token). After saving, we'll show you a Webhook URL and Verify Token to paste into WhatsApp → Configuration on Meta's side — that last step is a manual click on Meta's dashboard, there's no API for it.

Connect Facebook Page

From Meta for Developers → your App → Messenger → Settings, generate a Page Access Token for the Page you want to connect. After saving, paste the Webhook URL and Verify Token we show you into Messenger → Settings → Webhooks on Meta's side.

Connect Instagram

Instagram Direct messaging runs through the Facebook Page linked to your Instagram professional account — link that in Meta Business Suite first if you haven't. Then use the SAME Page Access Token as your Facebook channel (or generate a fresh one from Meta for Developers → your App → Messenger → Settings). After saving, paste the Webhook URL and Verify Token shown below into your Meta App's Instagram → Configuration page.

Connect LinkedIn

LinkedIn profile sharing uses a LinkedIn Access Token. Provide your Member Access Token below to publish posts/shares directly to your feed from the Content Studio or via Automation Workflows.
