Account Policy
  • Single admin account. Only one user can hold the admin role at a time — attempting to promote a second account is blocked automatically, and the last remaining admin can't be demoted (that would lock everyone out).
  • Session timeout. You'll be signed out automatically after 10 minutes of inactivity.
  • New-device alerts. Logging in from an IP address not seen before sends an email alert to your admin notification address. (Real-time SMS-to-phone would need a paid SMS API like Twilio — not configured here.)
