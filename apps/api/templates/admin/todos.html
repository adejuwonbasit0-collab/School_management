Reminder Setup

While you're logged into admin, due reminders pop up as a toast automatically — nothing to set up for that. For a reminder to email you even when you're not logged in, this site has no background task runner, so it needs an external scheduler to "wake it up" periodically:

  1. Set a secret key below (any random string).
  2. On PythonAnywhere: Dashboard → Tasks → add a scheduled task that runs every 5–15 minutes: curl "https://yoursite.com/admin/api/check-reminders?key=YOUR_KEY"
  3. Any due, unsent reminders get emailed to the task's owner at that point.
