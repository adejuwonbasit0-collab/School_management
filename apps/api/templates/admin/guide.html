🏠 Public Site Structure

What your visitors and customers interact with. Managed directly from the Admin Dashboard:

  • Home Page — Displays the hero section (supporting slideshow carousel with manual next/prev buttons and background video), client projects list, dev trends, and testimonials.
  • Portfolio & About — Displays bio profile info, experience milestones, certifications, and developer skills.
  • Hire Me Intake — Customer-facing project onboarding form. Submissions populate the admin Project Requests funnel automatically.
🎯 Client Lifecycle Flows

The complete customer engagement cycle in one unified platform:

  • Request Intake — Client submits a project inquiry via the "Hire Me" form.
  • Proposal & Quote — Admin reviews the request, drafts a timeline, sets a proposal amount, and sends the proposal. Currency formats (USD/NGN) align with site configurations dynamically.
  • Acceptance & Setup — Client accepts the quote, selecting their preferred payment cycle (Full, Split, or After-service). An active Client Project with tracking milestones is generated.
  • Payment Verification — Client submits transaction references (for manual Bank Transfer or Cryptocurrencies) with uploaded image screenshots as receipt proof. Admin verifies the proof in Confirm Payments and approves.
📡 Content Studio & AI Generators

Create content variations, script briefs, and custom graphics in Admin → Content Studio:

  • Website Scanner — Continuously parses blog articles, services, and products (including pricing, tags, links) to propose custom target post opportunities automatically.
  • Copy Composer & Optimizer — Drafts captions, emails, or blogs. The "Optimize Copy" tool parses drafts to recommend variations and trending hashtags.
  • Short Video Outliner — Creates Reels/Shorts script breakdowns (Hook, visual scene cues, CTA outliners) matching specified topics.
  • DALL-E Graphics — Generates custom graphics with OpenAI DALL-E and downloads them to your local assets folder instantly.
💬 Unified Inbox & Sentiment Analytics

Communicate across platforms in Admin → Conversation Inbox:

  • Omnichannel Messages — Syncs communications from Telegram, WhatsApp, and Facebook Messenger.
  • Sentiment Analysis — Categorizes customer moods (Positive, Neutral, Negative) and displays visual progress bars of customer happiness.
  • AI Suggested Replies — Drafts quick replies using brand guidelines, target audience restrictions, and forbidden vocabulary.
📝 Rich Notebook Workspace

Write corporate guidelines, draft blogs, and structure guidelines in Admin → Notebook Workspace:

  • Word-like Toolbar — Includes formatting (bold/italic/strikethrough), paragraph headers, lists, custom tables builder, and horizontal dividers.
  • Inset Note Boxes — Insert beautiful blue notification callouts or yellow warning boxes into notebooks.
  • Ready Templates — Insert pre-formatted checklist structures or pricing tables instantly.
🛠️ AI Developer Console

Perform codebase updates, binding verifications, and asset configurations in Admin → AI Developer Tool:

  • Hero Video BG — Toggle background types between particles, slideshows, and video streams.
  • Verification Checks — Run integrity tests on payment proofs, balanced bento card columns, and custom skill badges.
🪧 Site Popups (Website Automation)

Show overlay modals to site visitors without loading external libraries in Admin → Site Popups:

  • Trigger Options — Show popups after a time delay, on exit-intent (mouse moves out of viewport), or scroll completion.
  • Targeting & Frequency — Limit overlays to specific URL patterns (like `/blog`) and frequency rules.
📧 Email Drip Sequences

Build multi-step automated email funnels in Admin → Email Sequences:

  • Enrollment Triggers — Enroll users manually or automate triggers upon new newsletter signups.
  • Sequence Steps — Draft emails with dynamic variables like {% raw %}{{name}}{% endraw %}.
🤝 Partners & Custom Settings

Configure global features and brand logos in Admin → Site Settings:

  • Partners upload — Manage corporate partner logos (names, image links) to display on the home page.
  • Site Currency & Config — Update regional currencies (USD, NGN, EUR, etc.) and configure payment details.
