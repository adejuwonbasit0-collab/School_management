How to actually make this run automatically →

This server has no background task runner, so "every N days" needs an external nudge — this is the same pattern as reminders (Admin → To-Do → Reminder Setup), just for backups:

  1. Set a secret key below (any random string, different from your reminder one).
  2. On PythonAnywhere: Dashboard → Tasks → add a scheduled task that runs daily (that's the finest interval PythonAnywhere's free tier allows) hitting:
    curl "https://yoursite.com/admin/api/run-scheduled-backup?key=YOUR_KEY"
  3. Even though the task runs daily, a backup only actually happens once due — either your "Run every" interval has elapsed, or (if you picked "a specific date every month") today matches that day and it hasn't already run today — so set the external task to run daily regardless of which schedule type you pick; my code decides if it's actually due.
